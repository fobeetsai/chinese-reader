# 華語閱讀大師 · Chinese Reading Master

**日籍工程師のための中国語リーディング＆文法解析ツール**

單檔互動網頁：貼上中文文章，即時得到分詞、拼音／注音、HSK 分級、日文釋義與語法分析，並用微軟自然人聲朗讀。全部在瀏覽器端完成，不需後端、不需安裝。

🔗 **線上版**：https://fobeetsai.github.io/chinese-reader/

---

## 功能

### 📥 文章輸入
- **貼上文章**：繁簡自動辨識，依句讀切句後逐句解析
- **精選範例**：6 篇工程師場景文章，已內建人工日文譯文，離線可用
- **檔案匯入**：Word (.docx)、PowerPoint (.pptx)、Excel (.xlsx)、PDF、TXT、Markdown、CSV、字幕 (.srt/.vtt)、HTML —— 全部在瀏覽器端解析，**檔案內容不會上傳**
- **圖片 OCR**：相片或截圖可直接辨識中文（延遲載入 OCR 引擎，需連網）
- **網址讀取**：透過公開 CORS 代理取得網頁正文，自動過濾導航與廣告

> 舊格式 `.doc` / `.ppt` / `.xls` 為二進位格式，純前端無法可靠解析，請另存為新格式。掃描版 PDF（無文字層）請改用圖片 OCR。

### 🔍 解析與標註
- **分詞**：47,220 詞的分詞字典，採最長匹配並處理過度分詞（「我们的」→「我们」+「的」）
- **雙標音**：拼音與注音可切換；注音含空韻處理（`shī` → ㄕ）、一聲不帶調號
- **多音字**：詞級讀音修正（銀行 háng／音樂 yuè、長大 zhǎng／長度 cháng、伺服器 **sì** fú qì）
- **助詞讀音依語境判斷**：中文最高頻的兩個助詞「得」「著」字級讀音只有一種，硬套會唸錯，故依前後詞語境自動判斷——
  - 得：`跑得很快` → **de**（補語助詞）／`我得走了` → **děi**（必須義）／`取得資料` → **dé**（實義）
  - 著：`顯示著錯誤` → **zhe**（持續態）／`睡著了` → **zháo**（結果補語）／`著手` `附著` `穿著` → **zhuó**（實義）
  - 判斷從嚴：語境不明時維持原讀音，不以猜測取代查表
- **HSK 分級**：1–6 級配色，另設「超綱」色；未收錄詞以字頻推估等級
- **日文釋義**：2,066 詞的詞彙庫 ＋ 1,000 高頻單字釋義庫 ＋ 約 300 條常用詞組譯義

### 📚 語法手冊（154 條）
可依 **17 個分類**與 HSK 等級瀏覽，支援繁簡互查搜尋：

| 分類 | 條數 | 分類 | 條數 |
| --- | --- | --- | --- |
| 連詞・複句 | 32 | 副詞 | 18 |
| 介詞 | 16 | 特殊句式 | 14 |
| 體貌（了・著・過） | 12 | 補語 | 11 |
| 助動詞 | 6 | 否定 | 5 |
| 語序 | 5 | 疑問句 | 5 |
| 助詞 | 5 | 句子與句型 | 5 |
| 詞類與構詞 | 5 | 量詞 | 4 |
| 強調句式 | 4 | 實務・技術文常見 | 4 |
| 重疊 | 3 | | |

每條含：**句型公式**、**日文解說**（與日語的對應差異、語序提示、使用場合）、**例句（附注音與拼音）與日文譯文**、**朗讀鈕**，以及「本文の例文」——自動列出這個語法點在你貼上的文章中出現的所有句子，**同樣附注音與拼音**。

例句的標音隨全站設定同步：切換繁簡時字形與標音一起轉換；把標音切到「無」時只留漢字。懸停單字卡與複習庫抽認卡的例句也附標音。

閱讀時，文章命中的語法點會另外列在「文法ポイント分析」區。

### 👆 懸停字典
游標移到任一單字即跳出卡片並**自動發音**，含拼音／注音、HSK 級與詞性徽章、日文釋義、例句、朗讀與收藏鈕。
- 卡片**固定在視窗上方**（右上／上中央／左上可選），不會遮擋內文
- 可拖曳紅色把手自由移動，位置會被記住
- 全文朗讀時滑鼠掃過不會打斷播放

### 🎯 練習
- **遮蔽模式**：遮注音／遮漢字／遮翻譯／**挖空**（答案存在 `data-ans`，未點擊時 DOM 中為空，複製也拿不到答案）
- 點擊揭示、再點遮回；支援「全部表示／全部かくす」
- **麥克風朗讀**：語音辨識比對，顯示準確度（需 HTTPS）
- **聽打挑戰**：聽人聲輸入漢字，逐字比對給分並標示錯字

### 🔊 語音
Web Speech API，自動優先挑選 Microsoft **Natural／Neural／Online** 自然人聲（Xiaoxiao、Yunxi、HsiaoChen 等），可選語音與調整語速。
**建議用 Edge 桌面版開啟**，才能取得線上自然人聲；Chrome 通常只有系統標準音。

### 其他
- **字體大小**：6 級（82%–156%），快速鍵 `+` / `-` / `0`（刻意不佔用 Ctrl，不影響瀏覽器自身縮放），設定會記住
- **繁簡轉換**、**日文／繁中雙語介面**
- **我的複習庫**：收藏單字與語法點，抽認卡複習，JSON 匯出匯入（localStorage 保存）

## 使用

直接開啟 `index.html` 即可，或部署到任何靜態網站空間（GitHub Pages、Netlify、Vercel 等）。

- **離線可用**：分詞、標音、語法分析、範例文章、發音、遮蔽練習、聽打、複習庫
- **需要連網**：圖片 OCR、網址抓取、自己貼上文章的即時日文翻譯（失敗時自動降級為內建詞彙庫逐詞對照）
- **麥克風朗讀需 HTTPS**：GitHub Pages 已自動提供，直接部署即可使用

## 內容與著作權說明

本 App 的語法手冊，其**分類體系**參考了下列著作的章節架構與華語教學語法的通行分類：

- 趙元任《漢語口語語法》
- 盧福波《對外漢語教學實用語法》
- 施春宏《漢語基本知識：語法篇》
- 姜麗萍《圖解基礎漢語語法》

**所有語法解說文字、例句、日文譯文，以及詞彙釋義、範例文章，均為本專案獨立撰寫，未複製任何出版品的內容。**

漢字讀音與繁簡對照資料由開源套件 [`pypinyin`](https://github.com/mozillazg/python-pinyin) 產生，詞頻統計用於未收錄詞的等級推估。
